# Scope Guardrails

## Must-Have Features (Phase 1)
- Free-form log box
- AI parser
- Review-before-save
- Timeline
- Totals
- Report card (brutal truth line)
- Weekly dashboard
- Edit/delete
- PWA install
- Export CSV/JSON
- `/settings` page
- Up to 3 invited testers, private only

## Do-NOT-Build List (Phase 1 Traps)
- Native iOS/Android apps
- Screen-time integration
- Public landing page
- Stripe/payments
- Social features
- Team workspaces
- Complex goals, streaks, badges, gamification
- Notifications
- Too many charts
- Medical claims or “ADHD treatment” positioning
- Full automatic tracking

## Validation Metrics
Phase 1 is a success if:
- You log 10 of 14 days.
- Each invited tester logs 7 of 14 days.
- Median time to submit a log < 30 seconds.
- ≥70% AI entries accepted without edit.
- Daily dashboard opened ≥80% of logging days.
- Weekly dashboard opened at least twice.

**Rule**: Any feature request not on the must-have list -> check this file, default answer is "not in Phase 1".

# Visuals Specification

Exactly four visuals, built exceptionally well — no chart sprawl. Lost vs Unlogged distinction is sacred in every visual.

## 1. Today's Scoreboard
Big numbers: Productive / Lost / Fuel / Unlogged + productive ratio + one plain-language truth line (deterministic template).

## 2. Day Timeline
Horizontal timeline from 05:00 to 24:00, colored blocks:
- Green (Trading/Deep Work)
- Blue (Agency/Business)
- Red (Distraction)
- Yellow (Life/Fuel)
- Gray gaps = unlogged time

## 3. Productive vs Lost Stacked Horizontal Bar
A large stacked horizontal bar chart (NOT a pie chart) comparing productive to lost time. Show daily and weekly versions.

## 4. Weekly Heatmap
7 day-columns colored green -> red by productive ratio + weekly truth line (e.g. "This week, you lost 7h 40m to distraction. That is nearly one full workday you handed away.").
